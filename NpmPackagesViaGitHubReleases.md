# Publishing and consuming npm packages via GitHub Releases

Sometimes I build a project in public, but as a personal project, I don't want to publish the package to the [npm](Npm) registry. However, a valid tarball generated by [`npm pack`](https://docs.npmjs.com/cli/v11/commands/npm-pack) or [`pnpm pack`](https://pnpm.io/cli/pack) is [installable as an npm package as well](https://docs.npmjs.com/about-packages-and-modules#about-package-formats).

Here's how I publish and consume npm packages via [GitHub](GitHub) Releases:

## Publishing

1. I use [`pnpm pack`](https://pnpm.io/cli/pack) to generate a tarball.
2. I use [`gh release create`](https://cli.github.com/manual/gh_release_create) to create a release, uploading the built package file as an asset.

See [notes-frontend build workflow](https://github.com/dtinth/notes-frontend/blob/348afa925923b7c1f07488f383b72320b2f73249/.github/workflows/build.yml) for an example of a [GitHub Actions](GitHubActions) workflow that does that.

## Consuming

To consume the package, I just pass the download URL to `pnpm add`, e.g.:

```bash
pnpm add https://github.com/user/repo/releases/download/v1.0.0/package-1.0.0.tgz
```
