---

**In my [VSCode](VSCode)-based [note-taking infrastructure](AboutNotes), I built the notes sidebar** that shows outgoing links, backlinks, similar notes, and most recently changed notes. This note describe how it's done.

![VS Code window showing notes sidebar](https://static.dt.in.th/uploads/2020/12/11/notes-sidebar.png)

The notes sidebar has been implemented as a [workspace-local extension](20201208T104844Z2958). Usually I use VS Code Power Tools, but in order to add new [views][treeview] an extension is required to be able to [specify][packagejson] [contribution points][package-contribute].

However, most of the extension logic is offloaded to the notes server.
The extension [makes an `axios` call][call] to the notes database server (which always runs on the notes server that I SSH into).

The sidebar generation logic actually lives in the notes server [sidebar.js](https://github.com/dtinth/notes-infrastructure/blob/main/src/sidebar.js), outside the VS Code extension. The notes server hot-reloads this file, so whenever I make change I just run "Refresh notes sidebar" to see changes without having to "Reload window".
