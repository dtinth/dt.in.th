# Dark mode in Bootstrap 5.3

[Bootstrap 5.3 introduced support for dark mode](https://getbootstrap.com/docs/5.3/customize/color-modes/). This note describes how to use it in a Vite project.

<!-- prettier-ignore-start -->

1. Install Bootstrap 5.3 and Popper.js:

   ```sh
   $ pnpm add bootstrap@5.3.0-alpha1 @popperjs/core
   ```

2. Set `data-bs-theme="dark"` on the `<html>` element:


   ```html
   <html data-bs-theme="dark">
   ```

<!-- prettier-ignore-end -->
