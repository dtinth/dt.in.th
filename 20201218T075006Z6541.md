title: Inspecting Windows Clipboard in PowerShell
---

**To inspect Windows Clipboard in [PowerShell](20201210T061820Z6648),** first gain access to the [`Clipboard`](https://docs.microsoft.com/en-us/dotnet/api/system.windows.forms.clipboard?view=net-5.0) class.

```powershell
Add-Type -AssemblyName System.Windows.Form
```

To list all the format:

```powershell
[System.Windows.Forms.Clipboard]::GetDataObject().GetFormats($false)
```
