title: Using async functions with chrome.runtime.onMessage
---

**Asynchronous <code>[chrome](20220130T174417Z8065).runtime.sendMessage</code> callback with `response` of `undefined`:**

[According to the docs][culprit], `chrome.runtime.onMessage.addListener` does not support async functions. Instead, the listener must return `true` to indicate asynchronous response. Otherwise, _“The message port closed before a response was received”_ will show up in `chrome.runtime.lastError`.

[culprit]: https://developer.chrome.com/docs/extensions/mv2/messaging/#simple:~:text=The%20sendResponse%20callback%20is%20only%20valid,if%20the%20sendResponse%20callback%20is%20garbage%2Dcollected.

To work around this, here is an asynchronous wrapper.

```js
function asyncMessageResponder(asyncFn) {
  return (request, sender, sendResponse) => {
    Promise.resolve(asyncFn(request, sender)).then(
      (result) => sendResponse({ result }),
      (error) => {
        console.error(error)
        sendResponse({ error: { message: error.message } })
      }
    )

    // Indicate that the message will be handled asynchronously.
    return true
  }
}
```

To use:

```js
chrome.runtime.onMessage.addListener(
  asyncMessageResponder((request, sender, sendResponse) => {
    // ...
  })
)
```
