title: Adding a Desktop environment to a Debian/Ubuntu server
---

Situation:

- I have a cloud server running Ubuntu [Linux](Linux). I want to add a desktop environment to it. I want to be able to use the server as a desktop computer without using [Docker](Docker).

- I want to run each component on-demand (e.g. by SSHing and running them inside [tmux](Tmux)) without using e.g. systemd.

- I want to remotely access the desktop environment from my laptop via VNC.

## Install a desktop environment

```sh
sudo apt install tigervnc-standalone-server xfce4 xfce4-terminal
```

## Create a password file

```sh
vncpasswd
```

## Start VNC + X server

```sh
Xtigervnc -geometry 1920x1080 -listen tcp -localhost -AlwaysShared -AcceptKeyEvents -AcceptPointerEvents -SendCutText -AcceptCutText -PasswordFile ~/.vnc/passwd :0
```

## Start desktop environment

```sh
env DISPLAY=:0 xfce4-session
```
