title: Creating encrypted directories in a Linux VPS with gocryptfs
---

Creating encrypted directories in a [Linux](Linux) VPS with [gocryptfs](https://nuetzlich.net/gocryptfs/)^[Given that [encfs is not recommended, gocryptfs seems to be a good alternative](https://askubuntu.com/questions/813290/encfs-insecure-what-to-use-now)].

```sh
# Create directories
mkdir .vault .vault-contents

# Initialize gocryptfs
gocryptfs -init .vault

# Mount gocryptfs
gocryptfs .vault .vault-contents
```
