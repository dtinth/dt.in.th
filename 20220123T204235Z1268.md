# npm package version management

Tools that help with releasing new versions of npm packages and generating change logs.

Commit-based solutions

- [semantic-release](https://github.com/semantic-release/semantic-release)
- [standard-version](https://github.com/conventional-changelog/standard-version)

File-based solutions

- [rush change](https://rushjs.io/pages/best_practices/change_logs/)
- [news-fragments](https://github.com/grupoboticario/news-fragments)
- [changesets](https://github.com/changesets/changesets)
