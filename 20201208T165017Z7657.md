**In [IndieWeb](IndieWeb)'s webmentions system, you are expected to mark up your links appropriately.**
This tells the target website what kind of a mention it is.
Is it a [comment/reply](https://indieweb.org/reply), a [like](https://indieweb.org/likes), a [repost](https://indieweb.org/reposts), a [quotation](https://indieweb.org/quotation), a [bookmark](https://indieweb.org/bookmark), or just a generic [mention](https://indieweb.org/mention)?

For example, I recently added [Amber Wilson's post](https://amberwilson.co.uk/blog/grow-the-indieweb-with-webmentions/) to my list of links about the [IndieWeb](IndieWeb).
I did not explicitly mark that link as a bookmark (using `u-bookmark-of` class). As a result, my note was incorrectly classified as a comment.
This caused the entirety of my post's contents to appear there as a comment. (Sorry 😢)

![Example of my note appearing as a reply.](https://static.dt.in.th/uploads/2020/12/09/webmention-before-fix.jpg)

By the way, [take a look at webmention.io's test directory to see an example of each type of markup.](https://github.com/aaronpk/webmention.io/tree/main/test/data/source.example.org)
Once the link has been properly marked up as a correct kind, the result appears correctly.

![Example of my note appearing as a bookmark.](https://static.dt.in.th/uploads/2020/12/09/webmention-after-fix.png)

</div>

This can cause some inconvenience when authoring contents using a [Markdown](Markdown) file as Markdown links don't support classes.

One solution is to just write the HTML manually.

```markdown
<a href="..." class="u-bookmark-of">Author (year), "Title"</a>
```

But that is just too cumbersome. Instead, I decided to **use an emoji** to designate the type of link.

```markdown
[🔖 Author (year), "Title"](...)
```

The notes server is using [markdown-it](https://github.com/markdown-it/markdown-it) to render Markdown, like [VuePress](20201121T193504Z7144). So, I created a simple plugin to add `class="u-bookmark-of"` to links with 🔖 emoji.

```js
markdown.use((markdown) => {
  markdown.renderer.rules.link_open = ((original) =>
    function (tokens, idx, options, env, self) {
      const token = tokens[idx]
      const nextToken = tokens[idx + 1]
      if (nextToken && nextToken.type === 'text') {
        if (String(nextToken.content).startsWith('🔖')) {
          // https://github.com/aaronpk/webmention.io/blob/main/test/data/source.example.org/bookmark-of.html
          token.attrPush(['class', 'u-bookmark-of'])
        }
      }
      return original(tokens, idx, options, env, self)
    })(markdown.renderer.rules.link_open)
})
```
