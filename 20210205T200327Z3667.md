I encountered a problem where my 7-year-old MacBook slows down, and more strangely, **always have less than 10 gigabytes of disk space left, no matter how many files I removed.**

So I used DaisyDisk to scan my drive. It shows that **149.9 GB** is “hidden space.”

![](https://static.dt.in.th/uploads/2021/02/05/HiddenSpace.png)

Following [the docs](https://daisydiskapp.com/manual/4/en/Topics/HiddenSpace.html?subtopic=StillHiddenSpace&source=HiddenSpace&appEdition=Standard&appVersion=4.11&osVersion=10.15.7):

> Large amounts of hidden disk space may also indicate errors in the file system. You can use the [Disk Utility](http://support.apple.com/kb/HT1782) to verify and repair your disk's integrity. In some cases, you may need to boot your Mac in Recovery mode and run the Disk Utility from there.

So, using Disk Utility I tried to run first aid on my system partition.

![](https://static.dt.in.th/uploads/2021/02/05/FirstAidFail.png)

So I try to follow the instructions:

- [🔖 Mac is Getting the Btn: Invalid Key Order Error - Software Tested](https://softwaretested.com/mac/what-to-do-when-your-mac-is-getting-the-btn-invalid-key-order-error/)
- [🔖 macos - APFS: Snapshot is invalid - Ask Different](https://apple.stackexchange.com/questions/384070/apfs-snapshot-is-invalid)
- [🔖 macos - Deleting files and empty trash does not increase free space - Ask Different](https://apple.stackexchange.com/questions/378473/deleting-files-and-empty-trash-does-not-increase-free-space)
- [🔖 Deleting files not reclaiming disk space - Drive almost full | MacRumors Forums](https://forums.macrumors.com/threads/deleting-files-not-reclaiming-disk-space-drive-almost-full.2247672/)

Apparently the only way to fix is to back up the data and reinstall. Which……………

I guess it’s time.
