# สร้างเว็บแหล่งความรู้สวยๆ ด้วย VitePress

:::lead
A [talk](Talks) exploring [VitePress](VitePress), a static site generator for creating beautiful documentation and knowledge websites.
:::

In this talk, I share my experience using VitePress to build various websites, highlighting its features like default responsive theme, easy customization, Vue in Markdown for interactive components, and typography techniques for Thai language formatting. Presented at [BKK.JS #19](https://creatorsgarten.org/event/bkkjs19).

::youtube[szr7swXqPSw]

::cta[Read the transcript]{href="https://creatorsgarten.org/videos/bkkjs19/vitepress"}

## Highlights

- [VitePress](VitePress) allows easy creation of documentation sites
- Supports custom theming and components
- Provides layout slots for advanced customization
- Offers good typography and responsive design out of the box
- Great developer experience as the spiritual successor to [VuePress](VuePress)
- For websites I built with VitePress, see [Websites I built with VitePress](VitePress#websites-i-built-with-vitepress)
