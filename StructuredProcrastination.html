Structured procrastination

เพิ่งเจอเว็บ “structured procrastination” อ่านแล้วรู้สึก resonate มากๆ 😂

เขาบอกว่าคนที่เป็น ‘structured procrastinator’ อาจจะต้องทำ task A ที่สำคัญมากๆ แต่ไม่น่าทำเท่าไหร่ เลยทำ task B, C, D, E, F แทน เพื่อที่จะไม่ต้องมาทำ task A

พอ task A ใกล้ถึง deadline ก็อาจจะรับ task G เข้ามา ที่มันสำคัญและไม่น่าทำกว่า ถึงจุดนั้นก็อาจจะมาทำ task A เพื่อที่จะไม่ต้องทำ task G แทน กลายเป็นคน productive เฉย

พอเริ่มเห็นแพทเทิร์นว่าการทำงานของตัวเองเป็นแบบนี้ ก็อาจจะช่วยให้ไม่ต้องรู้สึกแย่กับตัวเองที่เป็นนักผัดวันประกันพรุ่งอีกต่อไป ลองเข้าไปอ่านในเว็บดู ตัวอย่างเห็นภาพมากๆ
