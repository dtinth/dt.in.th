The [Web MIDI API](https://developer.mozilla.org/en-US/docs/Web/API/Web_MIDI_API) provides a means for [web](WebPlatform) developers to enumerate, manipulate and access MIDI devices.

- [Major scale practice trainer](PianoMajorScaleTrainer) uses Web MIDI API to receive input from a MIDI keyboard.

## Talks

## Projects

- [WebMIDICon](WebMIDICon) - hackable MIDI controller web app
- [midi-rtc](https://github.com/dtinth/midi-rtc) - send and receive MIDI messages over WebRTC data channels
