title: Audio encoding CPU performance on M1 Macs
---

This table shows the speed of [encoding 5 minutes of white noise using ffmpeg](AudioEncodingBenchmark) on an M1 MacBook Pro. Encoding is performed 5 times, showing the best result:

| Environment                       |  Speed |       Comparison |
| --------------------------------- | -----: | ---------------: |
| Native                            | 232.0x |         Baseline |
| Rosetta 2                         |  63.1x |  **3.7x slower** |
| Docker ([Colima][]) linux/aarch64 |  51.0x |  **4.5x slower** |
| Docker ([Colima][]) linux/x86_64  |   5.5x | **42.2x slower** |
