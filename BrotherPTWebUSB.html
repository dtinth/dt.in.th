notes.dt.in.th

A web-based printing tool for Brother P-touch series label printers

The Brother P-touch series of label printers are popular for their ease of use and portability, and Brother has made their printing protocol publicly available, which allows developers to create custom software for these printers.

Warning

This tool has only been tested with the Brother PT-P710BT printer with tapes of size 18mm. Other printers and tape sizes are not supported. However, the code is open source. If you manage to get it working with other printers or tape sizes, feel free to submit a pull request.

Please connect to the printer to get started.
