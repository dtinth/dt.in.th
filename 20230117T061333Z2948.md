title: Running pgAdmin in Docker Compose
---

[pgAdmin](https://www.pgadmin.org/) is a web-based PostgreSQL [database](Database) management tool. To run it in [Docker Compose](DockerCompose), add the following snippet to your `docker-compose.yml`:

<!-- prettier-ignore-start -->

```yaml
  pgadmin:
    image: "dpage/pgadmin4:latest"
    environment:
      PGADMIN_DEFAULT_EMAIL: admin@example.com
      PGADMIN_DEFAULT_PASSWORD: password
      PGADMIN_LISTEN_ADDRESS: "127.0.0.1"
      PGADMIN_LISTEN_PORT: 5050
    network_mode: host
```

<!-- prettier-ignore-end -->

- Replace `latest` with [a version number that is compatible with your Postgres version](20230117T063739Z2762), e.g. `6.12`.
