Some lightweight tools available on this site:

ToolDescription
Major scale practice trainerPractice major scales on the piano with a MIDI keyboard.
Mnemonic code randomizerGenerates a random mnemonic code (e.g. ‘keyboard-herald’) using the SLIP39 wordlist.
Oklab visualizerVisualizes the A-B plane of the Oklab color space within sRGB.
OKLCH colors cale plotterPlot color scale in the OKLCH color space (LC and LH).
Paste image to decode QR codePaste an image containing a QR code to decode it in your browser.
Paste image to open in new tabPaste an image on this page to open it in a new tab so you can then drag it into other apps.
Port number randomizerGenerates a random port number for use in new projects.
Pomodoro timerMinimal Pomodoro timer with attention blinks and wake lock.
Pointer events testerTest pointer events on your device.
Web-based printing tool for Brother P-touchPrint labels using a Brother P-touch label printer from your browser.
