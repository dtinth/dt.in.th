title: Setting up Tailscale on a Linux VPS
---

Setting up [Tailscale](https://tailscale.com/) on a Linux machine is straightforward:

1. Sign in to <https://tailscale.com/admin>
2. Click **Add device** &rarr; **Linux server**
3. Add a tag, like `tag:cloud`
4. Click **Generate install script** and copy the script and paste it in its terminal
