OpenThai 2.0 OCR in the browser

OpenThai 2.0 OCR is a new OCR model from iApp Technology that reads Thai and English, released on November 12, 2026. It's free (Apache-2.0 licensed) and it's only 4 MB large.

Using ONNX Runtime Web, it is possible to run this model on the web browser. In this demo, after downloading the runtime and the model (~20 MB combined), everything afterwards happens on your device.

About the demo

  • Model: iapp/OpenThai2.0-OCR-Text by iApp Technology, Apache-2.0. It is based on PaddlePaddle PP-OCRv6-tiny.
  • Parts: a text detector (det.onnx) finds the text boxes. A line reader (rec.onnx) reads each box.
  • Guide: How to run OpenThai 2.0 OCR on iApp's blog.
  • Differences from official Python demo: This page is a JavaScript port of the model's Python runtime (runtime/line_engine.py). It skips page rotation, deskewing and column-gap splitting, so tilted photos can come out worse than in the original.
  • Demo source code: See OpenThaiOCRWebDemo.md.
