[**Elysia**](https://elysiajs.com/) is a high-performance, [TypeScript](TypeScript)-first web framework designed for building fast and scalable server-side applications with a focus on simplicity and developer experience, featuring end-to-end type safety. It is optimized for [Bun](Bun) but [also works on all WinterCG-compliant JavaScript runtimes](https://elysiajs.com/at-glance.html#platform-agnostic).
